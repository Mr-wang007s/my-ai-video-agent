# API 调用规范

## 环境变量管理

- 所有 API Key 存储在项目根目录 `.env` 文件中
- 禁止在代码、Agent 定义、Skill 文件中硬编码 API Key
- `.env` 已在 `.gitignore` 中排除
- 使用 `.env.example` 作为模板记录所需变量名

## 成本控制策略

### 生成前估算

| API | 单次调用成本估算 | 单日建议上限 |
|-----|----------------|-------------|
| Seedance 2.0 (5s/1080p, 含音频) | ~3.67 元 | 50 次 |
| Seedance 2.0 (10s/1080p, 含音频) | ~7 元 | 30 次 |
| Seedance 2.0 (15s/1080p, 含音频) | ~10 元 | 20 次 |
| DALL-E 3 (1024x1024) | ~0.28 元 | 100 次 |
| 火山 TTS (仅 Override 用) | ~0.01 元/千字 | 不限 |
| SD API (本地) | 0 元 | 不限 |

### Seedance 2.0 成本优化

- **优先使用 5s 时长**：大部分镜头 5s 即可，避免浪费
- **仅关键镜头用 10s/15s**：动作镜头、转场镜头
- **720p 预览**：先用 720p 测试效果，确认后再生成 1080p
- **音视频联合省成本**：无需单独付 TTS 费用（Seedance 自带音轨）
- 视频 URL **24h 有效**，生成后必须及时下载

### 控制手段

- 生成前记录 `generations` 表（status=pending），生成后更新 cost 字段
- 每日累计成本超过阈值时发出警告（通过 db_manager.py 查询）
- 优先使用本地 SD API，节省图像生成成本
- 视频生成前先确认分镜图质量，避免浪费

## 重试机制

- API 调用失败后最多重试 3 次
- 重试间隔：1s → 3s → 10s（指数退避）
- 超时设置：
  - 图像生成 60s
  - Seedance 视频提交 30s + 轮询 900s（15分钟，15s 视频需更长时间）
  - TTS 30s
- 连续 3 次失败后记录错误并跳过，不阻塞流水线

## 错误处理

- 所有 scripts/*.py 脚本统一输出 JSON 格式：`{"status": "success/failed", "error": "..."}`
- 退出码：0 = 成功，1 = 失败
- 错误日志格式：`%(asctime)s [%(levelname)s] %(message)s`
- 关键错误写入 `generations` 表的 `error` 字段

## 并发控制

- 同一 API 不并发调用（避免触发限流）
- 不同 API 可并行调用（如同时生成图片和 TTS）
- Seedance 2.0 API 限制：建议同时不超过 5 个任务
