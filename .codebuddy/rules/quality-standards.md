# 画面质量标准

## 分辨率要求

- 最终输出视频：最低 1080p (1920x1080)，推荐 2K
- 分镜图片生成：最低 1024x1024，推荐 1024x1536（竖版漫剧）或 1536x1024（横版）
- 角色参考图：最低 512x512

## Seedance 2.0 视频质量

- 原生支持 1080p 输出
- 宽高比选项：16:9 / 9:16 / 1:1 / 4:3 / 3:4 / 21:9
- 时长选项：4s / 5s / 10s / 15s
- 自带双声道立体声音轨

## 画面一致性

- 同一场景内，背景风格、光照方向、色调必须保持一致
- 角色外观在所有镜头中通过 **@ 引用参考图** + **prompt_template** 双重保障一致性
- 同一话/集内，整体画风不允许出现显著跳变
- 使用 Seedance 2.0 的多镜头叙事能力保持跨场景一致性

## 生成质量检查清单

### 图片质量
- [ ] 无明显的面部畸变（多余手指、扭曲五官）
- [ ] 角色辨识度：观众能区分不同角色
- [ ] 文字/标志无乱码

### 视频质量
- [ ] 视频无明显闪烁或帧间跳变
- [ ] 动作流畅自然，符合物理规律
- [ ] 运镜稳定，无异常抖动

### 音频质量（Seedance 2.0 原生音轨）
- [ ] 音频与画面动作同步（偏差 < 300ms）
- [ ] 对白发音清晰可辨
- [ ] 环境音效与画面匹配
- [ ] 无明显的音频割裂或噪音
- [ ] 若音频质量不佳，标记 `needs_tts_override: true`

## Prompt 规范

- 所有文生图 Prompt 使用英文
- Prompt 必须包含风格前缀（如 `manga style,` `anime style,`）
- 每个 Prompt 必须包含角色的 `prompt_template` 片段
- 使用 negative prompt 排除常见缺陷：`low quality, blurry, deformed, extra fingers, bad anatomy`
- 音效 Prompt（audio_prompt）使用中文，描述具体音效和情绪
