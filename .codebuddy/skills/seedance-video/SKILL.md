# 视频 Prompt 优化

提供 AI 视频生成平台（可灵、Seedance 等）的 Prompt 编写技巧、动作词汇表和最佳实践。

## 概述

本 Skill 提供平台无关的视频 Prompt 优化知识，帮助生成高质量的 `video_prompt` 和 `audio_prompt`，供用户在可灵等平台手动生成视频时使用。

## Prompt 结构模板

```
{角色/场景描述}, {动作/运动描述}, {镜头运动}, {光影变化}, {情绪氛围}
```

## 图生视频 Prompt 要点

图生视频的 Prompt 重点描述**动态变化**（静态信息已在图片中）：

**正确写法**：
```
角色缓缓睁开双眼，微风吹动发丝，镜头慢慢推进，光影柔和变化
```

**错误写法**（重复描述图片已有内容）：
```
一个黑发年轻男人坐在办公桌前
```

## 文生视频 Prompt 要点

文生视频 Prompt 需要同时描述**画面内容**和**动态变化**：

```
一位穿白色连衣裙的年轻女子站在樱花树下，微风吹落花瓣，她闭眼深呼吸后缓缓睁开双眼，镜头从中景慢慢推进至面部特写，夕阳余晖洒在脸上
```

## 音频 Prompt 要点

`audio_prompt` 用于描述期望的音效/配音，供手动配音时参考：

```
# 环境音效
安静的夜晚，远处传来蛐蛐声，偶尔有轻微的风声

# 角色配音（与画面动作匹配）
年轻男性声音轻声说'又是一个加班的夜晚'，伴随键盘敲击声和鼠标点击声

# 背景音乐
舒缓的钢琴BGM，带有淡淡忧伤的氛围
```

## 动作词汇表

| 类别 | 关键词 |
|------|--------|
| 面部 | 缓缓睁眼、微笑、皱眉、泪水滑落、凝视远方 |
| 头部 | 轻轻点头、摇头、转头、抬头望天 |
| 手部 | 伸出手、握拳、挥手、拿起物品、轻轻触碰 |
| 身体 | 起身、坐下、走向前方、转身、倚靠墙壁 |
| 环境 | 风吹树叶、花瓣飘落、雨滴坠落、光影流转、烟雾缭绕 |
| 镜头 | 镜头推进、镜头拉远、镜头平移、环绕拍摄、低机位仰拍 |

## 可灵平台使用建议

- 上传关键帧图片后，Prompt 只需描述动态变化
- 角色一致性：上传角色参考图作为输入
- 推荐先用短时长（5s）测试效果，满意后再生成长片段
- 多角色场景建议分别描述每个角色的动作
- 运镜关键词直接写入 Prompt 即可

## 多镜头叙事策略

### 角色一致性
1. 为每个角色准备高质量参考图（`character_list/{Name}/best.png`）
2. 上传参考图到平台，保持每次生成使用同一参考
3. 在 Prompt 中保持角色描述用词一致

### 多镜头连续性
1. 相邻镜头使用相似的光影/色调描述
2. 动作承接：上一镜头结束动作 = 下一镜头起始状态
3. 同一场景内保持环境描述一致

### 音频策略
1. **有对白的镜头**：在 `audio_prompt` 中描述角色说的话 + 环境音
2. **纯画面镜头**：描述环境音效和 BGM
3. **情绪转折镜头**：通过音频描述强化情绪（如紧张时加入心跳声）

## 时长建议

| 镜头场景 | 推荐时长 |
|----------|---------|
| 快速切换/表情反应 | 4-5s |
| 标准镜头/对话/空镜 | 5s |
| 长对话/动作/全景展示 | 10s |
| 关键情节/复杂互动/长镜头 | 15s |
