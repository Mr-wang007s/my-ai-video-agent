# 音频提示词设计（prompt-audio）

完整的音频设计方法论，从 `voice-synthesis` 升级而来。覆盖环境音分层、对白表演指导、BGM 选择、音效设计，以及最终的 `audio_prompt` 构造与配音指南导出。

## 适用场景

- **Step 4c**（Layer 3 镜头创建）：为每个 Shot 生成 `audio_prompt`
- **Step 5**（导出制作指南）：输出完整配音操作指引

**输入**：Shot 数据 + 角色 voice 配置 + 场景情绪基调
**输出**：每个 Shot 的 `audio_prompt` + 配音操作指引

---

## 1. audio_prompt 构造公式

每个 Shot 的 `audio_prompt` 必须按以下四段式结构组织，用中文描述：

```
{环境音效}, {动作音效}, {角色对白+表演指导}, {BGM描述}
```

### 四段详细说明

| 段落 | 描述 | 示例 |
|------|------|------|
| 环境音效 | 场景底层氛围音，持续铺底 | `空旷的城堡大厅回声` |
| 动作音效 | 画面中可见动作产生的声音 | `冰晶凝结的清脆碎裂声` |
| 角色对白 | 带表演指导的台词 | `年轻女性惊异地说：'那个声音……我又听到了'` |
| BGM描述 | 背景音乐风格和情绪 | `空灵的钢琴BGM缓缓响起` |

### 构造规则

- 四段之间用**中文逗号**分隔
- 无对白的镜头省略第三段，但其余三段必须保留
- 无动作音效的静态镜头可用 `无明显动作音效` 占位
- 每段描述应具体、可执行，避免抽象形容

### 完整示例

```
暴风雪呼啸的山顶，风声中夹杂碎冰撞击声，
冰块崩裂的巨响伴随地面震颤，
年轻女性坚定而颤抖地说：'我不会再逃避了……*这次*，我要面对它'，
紧张的弦乐渐强转为壮阔的管弦乐全奏
```

## 2. 环境音分层设计

根据场景类型选择多层叠加的环境音，营造真实空间感。

### 场景类型 → 环境音层次表

| 场景类型 | 底层音（持续） | 中层音（间歇） | 点缀音（偶发） | 空间感描述 |
|---------|--------------|--------------|--------------|-----------|
| 室内/安静 | 空调嗡鸣、房间底噪 | 钟表滴答 | 远处车声、门外脚步 | 封闭、私密 |
| 室内/热闹 | 人群交谈嘈杂 | 杯碟碰撞、笑声 | 门开关声 | 喧闹、拥挤 |
| 室外/自然 | 风声、流水声 | 鸟鸣、虫鸣 | 树枝折断、动物叫声 | 开阔、宁静 |
| 室外/城市 | 车流声、远处引擎 | 人群嘈杂、脚步声 | 喇叭声、刹车声 | 繁忙、现代 |
| 室外/夜晚 | 虫鸣、夜风 | 远处犬吠 | 猫头鹰叫声、树叶沙沙 | 寂静、神秘 |
| 战斗/紧张 | 心跳加速声 | 金属碰撞、武器摩擦 | 呼吸急促、衣物撕裂 | 压迫、紧迫 |
| 魔幻 | 能量嗡鸣、低频共振 | 水晶共鸣、魔法回响 | 空灵铃声、元素爆裂 | 超自然、神秘 |
| 水域 | 水流涌动、波浪拍打 | 水滴回声 | 鱼跃出水、气泡声 | 深邃、流动 |
| 洞穴/地下 | 回声混响、水滴滴落 | 石块碎裂 | 蝙蝠振翅、远处坍塌 | 幽暗、封闭 |

### 分层叠加原则

- **底层音**：全程铺底，音量 40%，营造空间感
- **中层音**：间歇出现，每 3-5 秒一次，增加真实感
- **点缀音**：偶发出现，每 8-15 秒一次，防止听觉疲劳
- 场景切换时，环境音需 0.3-0.5s 交叉淡入淡出
- 同一场景内连续镜头的环境音**必须保持一致**

## 3. 对白表演指导

### 对白格式规范

标准格式：`{性别/年龄描述}{详细语气描述}说：'{台词内容}'`

#### 语气描述升级（从简单标签到细腻描述）

| 简单标签（禁用） | 细腻描述（必须使用） |
|----------------|-------------------|
| 生气地说 | 压抑着怒火、声音微颤地说 |
| 高兴地说 | 眼含泪光、又惊又喜地说 |
| 悲伤地说 | 哽咽着、声音逐渐破碎地说 |
| 害怕地说 | 倒吸冷气、声音发紧地低声说 |
| 平静地说 | 目光深远、用看透一切的淡然语气说 |
| 惊讶地说 | 猛地抬头、不敢置信地惊呼 |

### 停顿与重音标注

| 标注 | 含义 | 时长 | 示例 |
|------|------|------|------|
| `...` | 短停顿（犹豫、思考） | 0.5s | `'我觉得...也许你是对的'` |
| `——` | 长停顿（情绪转折、回忆） | 1.0s | `'那一年——一切都变了'` |
| `*词*` | 重音词（情感强调） | 加重语气 | `'这*不是*你的错'` |
| `！` | 语气上扬（感叹） | 自然 | `'快跑！'` |
| `？` | 语调上扬（疑问） | 自然 | `'你说什么？'` |

### 对白类型处理

| 类型 | 处理方式 | audio_prompt 写法 |
|------|----------|------------------|
| 角色对话 | 角色专属音色 + 情绪参数 | `年轻女性焦急地说：'快走！'` |
| 内心独白 | 角色音色 + 降速 20% + 轻声 | `年轻女性内心低语：'为什么会变成这样...'` |
| 旁白叙述 | narrator 音色 + 均匀语速 | `男性旁白平稳叙述：'那是一个寒冷的冬天'` |
| 呐喊/吼叫 | 高音量 + 快速 | `年轻男性竭力嘶吼：'不要！'` |
| 耳语/密语 | 低音量 + 气声 | `成熟男性压低声音神秘地说：'他们来了'` |
| 多人齐声 | 标注"齐声" | `众人齐声高呼：'出发！'` |

### 情绪-语音参数映射

| 情绪 | 语速调整 | 音量调整 | 语调 | 呼吸特征 |
|------|---------|---------|------|---------|
| neutral（平静） | 1.0x | 正常 | 平稳 | 均匀 |
| happy（喜悦） | 1.1x | 稍高 | 上扬 | 轻快 |
| sad（悲伤） | 0.85x | 稍低 | 低沉 | 叹息 |
| angry（愤怒） | 1.15x | 高 | 强烈起伏 | 粗重 |
| surprised（惊讶） | 1.2x | 高 | 急促上扬 | 倒吸气 |
| fearful（恐惧） | 1.1x | 低 | 颤抖 | 急促浅 |
| determined（坚定） | 1.0x | 稍高 | 沉稳有力 | 深长 |
| tender（温柔） | 0.9x | 低 | 轻柔 | 绵长 |
| mocking（嘲讽） | 1.05x | 正常 | 上扬拖长 | 不屑 |
| desperate（绝望） | 0.8x | 从高到低 | 破碎 | 不规则 |

## 4. BGM 选择矩阵

根据叙事节奏阶段（参照 `narrative-rhythm` 规则中的情绪曲线）选择 BGM。

### 情绪阶段 → BGM 配置

| 情绪阶段 | BGM 风格 | 乐器倾向 | 节奏(BPM) | 音量建议 |
|---------|---------|---------|----------|---------|
| 铺垫（前 20%） | 舒缓、轻柔 | 钢琴独奏、轻弦乐 | 60-80 | 30% |
| 发展（20%-60%） | 渐进、层次增加 | 弦乐组+轻鼓点 | 80-110 | 30-40% |
| 高潮（60%-85%） | 激烈、壮阔 | 管弦乐全奏+打击乐 | 120-160 | 40-50% |
| 收尾（后 15%） | 回落、余韵 | 独奏钢琴/吉他 | 50-70 | 25% |
| 悬疑 | 低频不和谐 | 电子音+弦乐颤音 | 不规则 | 35% |
| 浪漫 | 温暖、流畅 | 钢琴+大提琴 | 70-90 | 30% |
| 诙谐 | 轻快、跳跃 | 拨弦+木管+打击乐 | 100-130 | 35% |
| 恐怖 | 不和谐、低沉 | 低音弦乐+不协和音 | 不规则 | 35% |

### BGM 切换规则

- 同一情绪阶段内 BGM **不换曲**，仅调整强度
- 阶段切换时 BGM 用 2-3 秒交叉淡入淡出
- 高潮前可用 1-2 秒静音制造"屏息感"
- 连续镜头中 BGM 描述必须一致（除非明确标注情绪转换）
- audio_prompt 中 BGM 描述格式：`{情绪形容}的{乐器/风格}BGM{动态变化}`

### BGM 描述示例

| 场景 | BGM 描述 |
|------|---------|
| 角色初次相遇 | `温暖的钢琴旋律轻轻响起` |
| 发现线索 | `悬疑的弦乐颤音若有若无` |
| 战斗开始 | `激烈的管弦乐伴随鼓点骤然响起` |
| 战斗胜利 | `壮阔的铜管乐奏出胜利旋律` |
| 离别场景 | `哀伤的大提琴独奏缓缓流淌` |
| 喜剧桥段 | `轻快的拨弦伴随俏皮的木管` |

## 5. 音色映射表

每个角色在 `characters.json` 中定义 `voice` 字段：

```json
{
  "voice": {
    "voice_type": "young_female",
    "speed": 1.0,
    "emotion_default": "neutral",
    "signature_quality": "清澈透亮，带有微弱回音感"
  }
}
```

### 预定义音色类型

| voice_type | 描述 | 适用角色 | 音色特征 |
|-----------|------|----------|---------|
| narrator | 男性旁白 | 叙述者 | 沉稳、客观、节奏均匀 |
| young_male | 年轻男性 | 男主角（18-30） | 清朗、有朝气 |
| young_female | 年轻女性 | 女主角（18-30） | 清澈、自然 |
| mature_male | 成熟男性 | 长辈、Boss | 低沉、有威严 |
| mature_female | 成熟女性 | 女性长辈 | 温厚、从容 |
| child | 儿童 | 小孩角色 | 稚嫩、清脆 |
| hoarse_elder | 沙哑老者 | 智者、长老、老年角色 | 沙哑、苍老、带有岁月沉淀感 |
| cool_queen | 清冷御姐 | 女性反派、冰系角色 | 清冷、疏离、带有距离感 |
| lazy_youth | 慵懒少年 | 天才型角色、不羁少年 | 慵懒、漫不经心、偶尔认真 |
| lively_loli | 活泼萝莉 | 年幼女性角色、精灵 | 活泼、甜美、语速偏快 |

### 音色选型原则

- 同一角色全片使用**同一 voice_type**，不可中途更换
- 主角建议使用 `young_male` / `young_female`，辨识度高
- 反派建议使用 `mature_male` / `cool_queen`，与主角形成对比
- 配角音色需与主角有明显区分，避免混淆
- 同性别角色之间需通过 `signature_quality` 区分

## 6. 音量层次规范

所有音频元素按以下优先级分层混音：

### 标准音量层次

| 层次 | 音频元素 | 相对音量 | 说明 |
|------|---------|---------|------|
| 1（最高） | 角色对白 | 100% | 始终最清晰可闻 |
| 2 | 动作音效 | 70% | 配合画面动作，不掩盖对白 |
| 3 | 环境音效 | 40% | 持续铺底，营造空间感 |
| 4（最低） | BGM | 30% | 烘托氛围，不干扰对白 |

### 动态音量调整

| 场景条件 | 调整策略 |
|---------|---------|
| 有对白时 | BGM 自动降至 20%，环境音降至 30% |
| 无对白的动作镜头 | 动作音效升至 90%，BGM 升至 50% |
| 空镜/过渡镜头 | 环境音升至 60%，BGM 升至 50% |
| 高潮爆发瞬间 | 所有音效短暂齐平（0.5s），随后对白优先恢复 |
| 情绪静默（留白） | 所有音量降至 20% 以下，仅保留环境底噪 |

### 在 audio_prompt 中标注音量

当需要特殊音量处理时，在 audio_prompt 中显式标注：

```
（环境音渐弱）寂静的走廊，年轻女性屏住呼吸低声说：'有人来了'，BGM骤停
```

## 7. 角色声音身份设计

为主要角色建立完整的声音身份档案，确保全片配音一致性。

### 声音身份模板

每个主要角色应定义以下声音属性：

```json
{
  "name": "Elsa",
  "voice": {
    "voice_type": "cool_queen",
    "speed": 0.95,
    "emotion_default": "determined",
    "signature_quality": "清冷透亮，情绪激动时带有微弱颤音",
    "pitch_range": "中高音域",
    "breathing_pattern": "平稳深沉，魔法释放时呼吸加重",
    "speech_habit": "用词正式、句式简短，少用语气词",
    "accent_note": "无特殊口音，吐字清晰"
  }
}
```

### 声音属性说明

| 属性 | 说明 | 示例值 |
|------|------|--------|
| voice_type | 基础音色类型 | `cool_queen` |
| speed | 默认语速倍率 | `0.95`（略慢于标准） |
| emotion_default | 默认情绪基调 | `determined` |
| signature_quality | 标志性音质特征 | `清冷透亮，带有微弱颤音` |
| pitch_range | 音域范围 | `中高音域` / `低音域` |
| breathing_pattern | 呼吸特征 | `平稳深沉` |
| speech_habit | 说话习惯 | `用词正式、句式简短` |
| accent_note | 口音备注 | `无特殊口音` |

### 声音身份在 audio_prompt 中的应用

编写 audio_prompt 中的对白段时，需结合角色声音身份：

- 语气描述需体现角色 `signature_quality`
- 语速在 `speed` 基础上根据情绪调整
- 呼吸/停顿体现角色 `speech_habit`

**示例**（角色：Elsa，voice_type: cool_queen）：

```
清冷的女声用看透一切的淡然语气说：'冰雪不会伤害我——但*它们*会伤害你'
```

而非简单的：

```
女性平静地说：'冰雪不会伤害我但它们会伤害你'
```

## 8. 推荐配音工具

在最终合成阶段（剪映等工具中手动操作）使用：

| 工具 | 优势 | 适用场景 |
|------|------|----------|
| 剪映内置配音 | 免费、中文效果好 | 首选，大部分场景 |
| 剪映 AI 克隆 | 定制音色 | 主角专属音色 |
| ElevenLabs | 音色克隆强、情感表现力 | 英文或高要求场景 |
| 微软 Azure TTS | SSML 精细控制 | 需要精确语调控制 |

### 配音工作流

1. 打开导出的 `storyboard_guide.md`
2. 按镜头顺序浏览每个 Shot 的 `audio_prompt`
3. 在剪映中为每个镜头依次操作：
   - 添加环境音效（参考 audio_prompt 第一段）
   - 添加动作音效（参考 audio_prompt 第二段）
   - 使用 AI 配音录入对白（参考 audio_prompt 第三段的语气和台词）
   - 添加 BGM（参考 audio_prompt 第四段）
4. 按音量层次规范调整各轨道音量
5. 检查对白时间与画面动作的同步性
6. 检查场景切换处的音频过渡是否平滑

## 9. 质量检查清单

### audio_prompt 编写质量

- [ ] 四段式结构完整（环境音 + 动作音效 + 对白 + BGM）
- [ ] 使用中文描述
- [ ] 环境音与场景类型匹配（参照环境音分层表）
- [ ] 对白格式正确：`{性别/年龄}{详细语气}说：'{台词}'`
- [ ] 语气描述使用细腻描述而非简单标签
- [ ] 停顿标注正确使用（`...` / `——`）
- [ ] 重音词用 `*` 标注
- [ ] BGM 描述与当前情绪阶段匹配

### 角色声音一致性

- [ ] 同一角色全片使用相同 voice_type
- [ ] 同一角色的语气描述风格一致（体现 signature_quality）
- [ ] 不同角色的音色有明显区分
- [ ] 角色情绪变化符合剧情逻辑

### 音频节奏合规

- [ ] 对白时长符合 narrative-rhythm 规则的计算公式
- [ ] 对白间隔 >= 0.5s
- [ ] 内心独白语速比对话慢 20%
- [ ] 旁白语速稳定（180-220 字/分钟）

### 音量与混音

- [ ] 音量层次遵循标准（对白 100% > 音效 70% > 环境 40% > BGM 30%）
- [ ] 有对白时 BGM 自动压低
- [ ] 场景切换处有音频过渡处理
- [ ] 无明显的音量跳变或突兀静音

### 场景连续性

- [ ] 同一场景内连续镜头的环境音一致
- [ ] 同一情绪阶段内 BGM 风格一致
- [ ] 场景切换处环境音有 0.3-0.5s 淡入淡出
- [ ] 时间跳跃处有 0.2s 静音间隔
